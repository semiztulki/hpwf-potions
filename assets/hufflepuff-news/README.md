# The Practical Potioneer

Оформление поста в светлых хаффлпаффских тонах.

В комплекте: шапка, бумажный фон и пять заголовков разделов.
Шапка: The Practical Potioneer; подзаголовок — ПРАКТИКА ЗЕЛЬЕДЕЛИЯ,
прописными буквами, прямым тонким шрифтом.

## Файлы

- header.png — 720 × 320 пикселей.
- paper-background.png — 720 × 1080 пикселей.
- heading-curator.png — колонка куратора.
- heading-alchemy.png — достижения в области зельеварения и прикладной алхимии.
- heading-ingredients.png — кладовая ингредиентов.
- heading-owl.png — бонжур сова.
- heading-young-masters.png — юные мастера зелий.
- bbcode.txt — полный шаблон с Lorem ipsum.
- preview.html — автономный предварительный просмотр; откройте его рядом с изображениями.

Заголовки разделов: 664 × 221 пиксель, прозрачный фон PNG с альфа-каналом.
Надписи выполнены тонким прямым шрифтом, прописными буквами, с точками по сторонам.
Ширина поста: 720 пикселей. Прямые ссылки и BB-код сохранены.
Измените номер выпуска и замените Lorem ipsum своим текстом.
Любой раздел можно удалить целиком: от строки с его изображением до конца следующего текстового блока.

## Размещение изображений

В bbcode.txt подготовлены прямые адреса для публичной папки
semiztulki/hpwf-potions → assets/hufflepuff-news в ветке main.
Изображения размещены в указанной публичной папке; шаблон содержит готовые прямые ссылки.
Если вы выберете другое хранилище, замените начало URL во всём шаблоне.

На форуме ничего не публиковалось. Предпросмотр HTML приблизительный:
редактор форума может добавлять собственные поля и межстрочные интервалы.
